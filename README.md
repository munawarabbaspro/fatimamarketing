# Fatima Marketing website

Static website for **Fatima Marketing** (Fatima Group of Companies, FGC): Islamabad & Rawalpindi real estate.

- `website/`: the site (zero-dependency Node generator `build.mjs`, data in `src/data/`, assets in `src/static/`), media tools and tests. See `website/README.md`.
- `docs/`: requirements notes (every fact and its source), SEO/competitor audit and UAT report.
- `vercel.json`: Vercel config, generated by `website/build.mjs` (build `node website/build.mjs`, output `website/dist`, redirects and headers).

Local preview: `node website/build.mjs && node website/tools/serve.mjs 4173` → http://localhost:4173
